# Ejercicios de Circuitos Lógicos Programables (CLP)

**Especialización en Sistemas Embebidos — FIUBA, Universidad de Buenos Aires**

**Autor:** Carlos Quispe López  
**Lenguaje:** VHDL  
**Herramienta:** Xilinx Vivado 2018.3

## Descripción

Este repositorio reúne los ejercicios prácticos desarrollados durante el curso de Circuitos Lógicos Programables, correspondientes a la Especialización en Sistemas Embebidos de la Facultad de Ingeniería de la Universidad de Buenos Aires (FIUBA).

El objetivo de las prácticas es comprender el diseño de circuitos digitales mediante VHDL, utilizando diferentes estilos de descripción de hardware: por comportamiento, por flujo de datos y estructural.

Los ejercicios incluyen el desarrollo de circuitos combinacionales y secuenciales, así como archivos de simulación (*testbenches*) para analizar y verificar su funcionamiento.

## Ejercicios desarrollados

| N.º | Ejercicio | Descripción |
|---|---|---|
| 1 | Sumador completo de 1 bit | Implementación de un sumador con entradas A, B y acarreo de entrada |
| 2 | Sumador estructural de 4 bits | Construcción de un sumador de 4 bits mediante interconexión de componentes |
| 3 | Sumador-restador de 4 bits | Circuito que permite realizar operaciones de suma y resta |
| 4 | Multiplexor 2:1 | Selección entre dos entradas mediante una señal de control |
| 5 | Flip-flop tipo D | Flip-flop sensible al flanco ascendente con reset síncrono y habilitación |
| 6 | Registro de desplazamiento de 4 bits | Implementación estructural mediante flip-flops |
| 7 | Registro de desplazamiento por comportamiento | Descripción secuencial de un registro de desplazamiento |
| 8 | Barrel Shifter | Desplazador de N bits descrito por comportamiento |
| 9 | Barrel Shifter con multiplexores | Implementación mediante etapas de multiplexores 2:1 |
| 10 | Contador binario de 4 bits | Implementación estructural mediante flip-flops y compuertas lógicas |

## Organización del repositorio

Cada ejercicio se encuentra organizado en una carpeta independiente, facilitando la identificación del código VHDL y de los archivos de simulación disponibles.
